# Glossary - Black/Matrix +

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: kept, hyphenated (Johannes-san, Luca-sama). Name order: Western (given name first).
- Romanisation source: official English names where they exist, else an earlier fan patch, else Hepburn without macrons. This game has no official English; D9 takes the English Wikipedia cast list as the nearest thing, and standard English for biblical and angelic names.
- Credits: English.
- Register / flavour: modern, plain, characterful fan-translation English. Priests and angels formal. No Latin-flavour archaisms except where a text is scripture-like (D10). Sound effects: spelled out in English letters, loud ones in capitals (KSHAAA!, BOOM!).
- Abbreviations: full names and terms everywhere, prefer engine changes over shortening.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> "...", ＜＞ dropped or "...", ・・・ -> ..., ・・ -> ..., ！？ -> !?, ！！！ -> !!! at a climax, else !!. ～ dropped or kept as ~ where the drawl matters. Fullwidth letters and digits -> ASCII.
- Plain ASCII only: straight quotes, no curly quotes, no em dash (write -- or rephrase).
- The inverted morals stay inverted. Say "wicked" as praise, "hypocrite" as the insult for a kind person, "the sin of love". Never "correct" it.
- Thoughts in parentheses stay in parentheses.
- 俺/ボク/私 are all "I": the voice carries the difference.
